GitPulse — Chrome Extension

Repository activity at a glance, so you can tell whether an open source project is alive before you depend on it.

  • Role: Sole developer
  • Started: June 2025
  • Chrome Web Store
  • Source on GitHub

The Problem

Deciding whether to adopt a dependency usually starts with a question GitHub answers slowly: is anyone still working on this? The signals exist — commit recency, issue turnover, release cadence — but they are spread across tabs, and star count, the one number shown prominently, says almost nothing about whether a project is maintained today.

The intent was to save the loop of cloning a repository or clicking through the commit graph just to learn that the last meaningful change was two years ago.

What I Built

A browser extension that reads repository activity through the GitHub API and presents it as an at-a-glance status, surfaced where you are already looking instead of on a separate dashboard.

  • Activity visualization

    Repository metrics rendered compactly enough to read in the moment you are evaluating a project.

  • Zero-dependency front end

    Plain HTML, CSS, and JavaScript — an extension that ships no framework keeps its permissions narrow and its review surface small.

  • Published & open source

    Listed on the Chrome Web Store and developed in the open on GitHub, where the privacy policy and source are both public.

Notes

Shipping to the Chrome Web Store is a different discipline from shipping a web app: permissions are reviewed, a privacy policy is mandatory, and every additional API scope has to justify itself. That constraint pushed the design toward doing one thing with the narrowest access that could support it.

GitPulse also fits a pattern in the tools I build for myself — most of them exist to make an invisible signal visible, which is the same idea behind evaluation tooling for AI systems.
