♛EDITOR HELP

Using the card editor

  1. Design directly on the page.

    Click any element to select it. Drag to move, pull a corner to resize, or use the round handle to rotate. Double-click text to write. Use the Element studio for exact positions, colors, typography, animation, and more.

  2. Go beyond a template.

    Add text, photos, stickers, shapes, buttons, countdowns, and HTML from the canvas toolbar. Use Layers to select, hide, lock, duplicate, or stack elements. Hold Alt to skip snapping, Shift to constrain a drag, or use arrow keys to nudge.

  3. Make it interactive.

    Switch to Interact to test card opening, surprise messages, links, and celebrations. Code opens page CSS or the HTML and CSS of a selected HTML block. HTML blocks support native HTML interactions; scripts stay disabled.

  4. Keep it. Share it.

    Your draft saves in this browser. Save project makes a backup; Open project also reopens exported HTML. Download HTML, name it index.html, upload it to cards/your-party/, and share the URL.

One file really means one file.

Photos, layouts, custom styles, and Koz Engine effects travel with your download. Guests need no account. RSVP buttons open your form or their email app; collecting responses needs an external form or email address.
