# Documentation Integration

Documentation is part of the engine contract.

- Start with the root [`integration.md`](../integration.md).
- Use each domain folder's `integration.md` for ownership and extension hooks.
- Use `module-catalog.md` for current API/caveat details.
- Use `neonyke-extraction-map.md` to plan migrations from the host game.

When adding a module, update its folder guide, module catalogue, browser bridge entry if needed, and direct tests. Mark transitional host coupling explicitly.
